Winery Adventures
=================

Documentazione della pipeline di analisi dei dati dei sensori delle cisterne
di fermentazione. La pipeline carica le letture da file TSV, applica una
sequenza di trasformazioni, calcola l'indice di stress di fermentazione per
cisterna e produce il risultato arricchito.

L'indice seguente raccoglie la documentazione dei moduli del pacchetto,
estratta dalle rispettive docstring.
